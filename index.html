Python Indent Fixer

Paste Python code that lost its spacing. Fix the indentation, adjust anything that's off, then copy it or print one line per page.

1. Paste code

Splitting: two or more spaces, or a tab, start a new line. After a colon the next line is indented. A smaller gap than the one that opened a block moves the code back out.

2. Check and edit

Tab indents the selected lines. Shift+Tab outdents them. The tool can't know where every block ends, so check the spots where code moves back to the left.

3. One line per page (PDF)
