Python Indent Fixer

Paste Python code that lost its spacing. Fix the indentation, adjust anything that's off, then copy it or print one line per page.

1. Paste code or load a CSV

A ~ ends a program, so one paste can hold many. Splitting: two or more spaces, or a tab, start a new line. After a colon the next line is indented. A smaller gap than the one that opened a block moves the code back out, and a bigger gap than the block's first line makes a nested block.

2. Check and edit

A line with only ~ separates programs. Tab indents the selected lines. Shift+Tab outdents them. The tool can't know where every block ends, so check the spots where code moves back to the left.

3. Preview and download

Put the marker at the very end of a line to add one extra blank line after it in the PDF. The marker is never printed, and Copy code leaves it out. Clear the box to turn this off.

The CSV has one program per row, with line breaks and indentation kept inside the cell and blank-line markers removed. You can load it back in with the CSV picker in step 1.
